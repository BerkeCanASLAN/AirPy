# Changelog

## 0.1.0

First public release.

- PC audio (WASAPI loopback) streamed to AirPlay speakers via pyatv, including HomePod stereo pairs.
- Adjustable speaker buffer (50–1500 ms), clock‑drift correction, per‑speaker volume (also while idle).
- Tray app with auto‑start, automatic reconnection, PIN pairing flow, desktop shortcut and uninstall scripts.
- Phone file/text sharing over a QR code, Tailscale aware, iOS Shortcut walkthrough.
- AirPy Sync browser extension (Edge/Chromium) that delays video to match speaker latency, with a sync test page.
