      Add “Send to AirPy” to the Share menu

      Once set up, in Photos, Files or any other app tap Share and send the file straight to the PC. The PC does not appear in the AirDrop row; it shows up among the actions in the Share menu.

      1. Open the Shortcuts app, tap + to create a new shortcut and name it Send to AirPy.
      2. Tap ⓘ at the bottom and turn on Show in Share Sheet.
      3. Add the Get Contents of URL action and paste the address below into its URL field.
      4. Expand the action: Method → POST, Request Body → Form. Add a new field, choose the type File; key files, value Shortcut Input.
      5. Tap Done. If it asks for local network access on first use, allow it.
